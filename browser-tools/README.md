## Entries

| Entry | Description |
|---|---|
| [Browser-use](browser-use/) | Agent browser automation library and cloud platform. Core Python library is open-source (MIT License) and completely free to run locally (user pays for LLM tokens). Managed Browser Use Cloud offers browser hosting infrastructure; includes a free tier for indiv |
| [Browserbase](browserbase/) | Managed cloud browser platform for web scraping and AI agents. Free plan offers 1 hour (60 minutes) of concurrent browser session usage per month (max 15 mins/session, 1 concurrent browser, 7-day data retention). Developer plan is $20/month for 100 browser hou |
| [Camofox](camofox/) | Open-source Camoufox anti-detect browser automation runtime. Free to self-host under the Mozilla Public License 2.0; use it only for authorized automation and review upstream terms before deployment. |
| [ChangeDetection.io](changedetection-io/) | Website monitoring and change detection service. Self-hosted version is free and open-source (MIT license). Managed Cloud SaaS subscription starts at $8.99/month for up to 5,000 URLs, including managed proxies and browser-based checks. |
| [Novita AI Sandbox Browser](novita-ai-sandbox-browser/) | Free tier: $100 in Sandbox credits, valid for 90 days with no credit card required; 5 concurrent sandboxes, 1-hour maximum session length, 2 vCPU, and 4 GB RAM per sandbox. Topping up unlocks the paid tier with higher concurrency and longer sessions. |
