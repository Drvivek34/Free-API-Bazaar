# Cli Tools

Curated free API providers in the Free API Bazaar family.

> Part of **[Free API Bazaar](../README.md)** · Browse all bazaars at the **[Mega AI Bazaar](https://drvivek34.github.io/Mega-AI-Bazaar/)**.

Contributions must include a source, author, and license note.

## Entries

| Entry | Description |
|---|---|
| [BlogWatcher CLI](blogwatcher-cli/) | Command-line tool to register, track, scan, and notify new blog and RSS feed updates on the fly. |
| [GitHub API](github-api/) | GitHub API authentication token. Free accounts have standard API rate limits (60 requests/hour unauthenticated). Authenticating using a Personal Access Token (GITHUB_TOKEN) increases the rate limit to 5,000 requests/hour (up to 15,000 requests/hour for GitHub  |
| [Hermes Agent CLI](hermes-agent-cli/) | Local command-line wrapper enabling background agent task runs, persistent environments, and pairing triggers. |
| [Honcho](honcho/) | AI-native persistent memory library for stateful agents (developed by Plastic Labs). Licensed under AGPL-3.0 and completely free to self-host locally or via Docker, with standard configuration overrides (HONCHO_BASE_URL). The managed cloud service (api.honcho. |
| [Ollama](ollama/) | Fully local and permanently free. Run model architectures like Llama, Qwen, Mistral, and Gemma on local CPU/GPU. |
| [Qoder](qoder/) | Local developer utility for AI assistance, code generation, and terminal integration. |
| [WaCLI](wacli/) | WhatsApp CLI tool for sending, syncing, and alerting messages directly from the server command-line. |
