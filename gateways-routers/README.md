# Gateways & Routers

Free aggregators/routers (e.g. OpenRouter free tier) fronting many models.

> Part of **[Free API Bazaar](../README.md)** · [Mega AI Bazaar](https://drvivek34.github.io/Mega-AI-Bazaar/)

Each provider lives in its own sub-folder with a `README.md` recording: free-tier limits, models, auth, OpenAI-compatibility, and signup link.

Add via [CONTRIBUTING.md](../CONTRIBUTING.md) or the [submission form](https://github.com/Drvivek34/Free-API-Bazaar/issues/new/choose).

## Entries

| Entry | Description |
|---|---|
| [OpenRouter](openrouter/) | Free model variants use platform-level requests-per-minute and requests-per-day caps that can change by policy and account history. The official limits page says to check current usage through GET /api/v1/key and to honor X-RateLimit-* and Retry-After headers. |
