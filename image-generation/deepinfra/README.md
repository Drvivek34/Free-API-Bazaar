# DeepInfra

Does not offer a formal subscription-based free tier. However, users can perform unauthenticated testing of models with an empty api_key (rate-limited by IP address). Paid options are strictly pay-as-you-go based on token usage (e.g., starting at ~$0.02/1M tokens) or execution time for non-LLMs. Cached tokens are discounted (e.g., ~$0.145/1M tokens).
